Sobre o Projeto & Arquitetura

Conheça a organização do nosso site e o desenvolvimento do projeto sobre a profissão de Médico(a).

Estrutura de Navegação (Mapa do Site)

Organização das páginas HTML do portal sobre a profissão médica:

  • index.html — Apresentação da Medicina e visão geral da profissão
  • pages/habilidades.html — Habilidades, formação acadêmica e mercado de trabalho médico
  • pages/materiais.html — Banner de divulgação, landing page e proposta de e-book sobre Medicina
  • pages/sobre.html — Arquitetura do site, hospedagem e créditos do projeto

Por que GitHub Pages? (Site Estático)

Este portal foi desenvolvido com HTML5 e CSS3 como um site estático, hospedado gratuitamente via GitHub Pages.

Diferente de sistemas em PHP ou WordPress, ele não exige processamento no servidor nem banco de dados para exibir páginas informativas sobre a profissão médica, garantindo carregamento rápido e versionamento via Git/GitHub.
